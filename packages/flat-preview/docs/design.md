# LLLL 舞台 2D 层设计

## 目标

原格式谱面的**平面预览**：横轴 = 60 格轨道，纵轴 = 时间（向上递增，与游戏的下落朝向一致），音符与 Hold 链按真实几何落纸。

2D 层聚焦谱面形状，与 `packages/llll-preview` 的 3D 舞台共用谱面、选曲和播放时钟；`apps/web` 负责统一工作台与舞台内的模式切换。

## 渲染边界

`packages/llll-preview` 的 3D 渲染链围绕原版相机与场景层级搭建：世界坐标 → 透视相机 → 分层场景 → HUD。2D 层使用二维坐标和 Canvas，按时间轴、轨道和 Hold 几何组织画面。

两种舞台模式共享源格式和链语义，2D 渲染只依赖 Vite、TypeScript 与 Canvas 几何。

## 口径来源

源格式与链语义**以 `packages/llll-preview` 的实现为口径**（已用 617 张谱面语料与二进制 dump 交叉核验）：

| 项 | 口径 |
|---|---|
| 压缩 | raw-deflate（`DecompressionStream('deflate-raw')` 可直接解，浏览器原生） |
| 字段 | `Notes[].Uid / just / holds / Flags`，`Bpms[].Time / Bpm` |
| Flags 位域 | `type=f&15`、`r=(f>>>4)&63`、`r2=(f>>>10)&63`、`l=(f>>>16)&63`、`l2=(f>>>22)&63` |
| 串链 | 同 `(l,r)` → `(l2,r2)`，`Uid` 递增，`|just−holds[末]| < float32(1e-4)` 判连 |
| 同时押 | 判定时刻差 < 4 ms 分组 |

解析与几何模块按 workspace 包组织，`scripts/cross-check.ts` 用同一批谱面校验两种舞台模式的口径。

## 坐标系

原版轨道是世界空间里 `lanePitch × (lane − 29.5)` 的连续坐标（`laneWidthOpt` 默认 100 时 `lanePitch = 0.15`），60 格铺开为 `±4.5`。

2D 层只需要**相对关系**，故取单位轨宽 = 1：

```
x(lane) = lane − 29.5          // 范围 −29.5 … +29.5
左缘 = x(l) − 0.5,  右缘 = x(r) + 0.5
```

`l/r` 是 6 bit 轨道号（0…59），`l > r` 由解析层拒绝，故宽度恒为正。

## 布局

横轴 = 轨道（60 格，左→右 = 低轨→高轨），纵轴 = 时间（**向上递增**）。

游戏是下落式的——未来的音符从上方落下。2D 层沿用同一朝向，0 秒在内容底端、总时长在顶端，
读谱方向和游戏里一致。`timeY` 因此以谱面时长 `duration` 为锚。

代价：换轴会把谱面作者用 Hold 画的图形整体上下翻转（爱心、箭头等）。这是该朝向的固有取舍，
同一组航点在 3D 舞台里也是这个朝向，故与游戏观感一致。

镜像开关即 `x → 左界 + 右界 − x`（等价 `lane → 59 − lane`）。

## 音符几何

单格宽 = 1。音符横跨 `[l, r]`，绘制矩形 `x = l−29.5`，宽 `r−l+1`。

纵向按类型区分（高度单位为秒，随缩放换算为像素）：

| type | 名称 | 高度 | 说明 |
|---|---|---|---|
| 0 | Single | 固定小值 | 瞬时音符，只表达「在什么时刻、什么轨道」 |
| 1 | Hold | 真实时长 `end − time` | 纵向长度即按住时长，这是 2D 层最有价值的部分 |
| 2 | Flick | 同 Single | |
| 3 | Trace | 同 Single | |

**不搬 3D 侧的 `worldWidthOf(width) = ((width−6)×0.2+1.15)×0.75`**：那条公式把 60 轨映射到世界宽度 0.15/轨的缩放，是 3D 场景的观感口径，2D 层直接用格宽更忠实。

## Hold 链

一条链由多个节点串成，节点间是**独立的一次位移**，各自可能有 `l2/r2` 与多个 `holds` 航点。

渲染规则：

1. **节点顺序 = 源数组顺序**。同 tick 折返的航点（如谱面用 Hold 画出的图形）靠顺序表达路径，不得按 lane 二次排序。
2. 每个节点内部：从 `(l,r)` 线性插值到 `(l2,r2)`，其 `holds` 给出中间时刻。
3. 链内所有节点的路径连成一条折线，按 `type=1` 的样式绘制。

## 视图参数

| 参数 | 含义 |
|---|---|
| 纵向缩放 | px/s，决定谱面疏密 |
| 轨道宽度 | px/格，60 格总宽 |
| 滚动 | 拖动平移；`Shift + 滚轮` 改纵向缩放、滚轮改轨宽 |
| 镜像 | 左右翻转 |
| 定位 | 把指定时刻滚到视口底边 |
| 分组线 | 按 BPM 段与拍号画小节线（`Bpms` + `Beats`） |

`Beats` 段给出拍号（`Numerator/Denominator`），`Bpms` 给出速度段，二者共同决定小节线位置；`Offset` 保留在共享谱面数据中，供需要消费谱面偏移的舞台逻辑使用。
