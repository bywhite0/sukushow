# llll 平面谱面预览 实施计划

## 目标

原格式谱面的**平面预览**：横轴 = 60 格轨道，纵轴 = 时间（向上递增，与游戏的下落朝向一致），音符与 Hold 链按真实几何落纸。

不做 3D 透视、不做判定、不做音频同步对拍。定位是**看谱面形状**的工具，与 `llll-preview-web`（3D 对局观感）分工。

## 为什么另起仓库

`llll-preview-web` 的整条渲染链是围绕原版相机与场景层级建的：世界坐标 → 透视相机 → 分层场景 → HUD。平面视图只需要二维坐标，套进去等于把 3D 管线当底座再架空一层。

另起仓库后，源格式解析与链语义仍是同一套口径，但渲染退化成「一次画一堆矩形」，代码量与依赖都小一个量级。

## 口径来源

源格式与链语义**以 `llll-preview-web` 的实现为口径**（该仓库已用 617 张谱面语料与二进制 dump 交叉核验）：

| 项 | 口径 |
|---|---|
| 压缩 | raw-deflate（`DecompressionStream('deflate-raw')` 可直接解，浏览器原生） |
| 字段 | `Notes[].Uid / just / holds / Flags`，`Bpms[].Time / Bpm` |
| Flags 位域 | `type=f&15`、`r=(f>>>4)&63`、`r2=(f>>>10)&63`、`l=(f>>>16)&63`、`l2=(f>>>22)&63` |
| 串链 | 同 `(l,r)` → `(l2,r2)`，`Uid` 递增，`|just−holds[末]| < float32(1e-4)` 判连 |
| 同时押 | 判定时刻差 < 4 ms 分组 |

**不复制代码**：两个仓库各自持有一份解析实现，避免跨仓库引用。代价是口径漂移风险，用一张共享的契约测试兜底（见「验证」）。

## 坐标系

原版轨道是世界空间里 `lanePitch × (lane − 29.5)` 的连续坐标（`laneWidthOpt` 默认 100 时 `lanePitch = 0.15`），60 格铺开为 `±4.5`。

平面视图只需要**相对关系**，故取单位轨宽 = 1：

```
x(lane) = lane − 29.5          // 范围 −29.5 … +29.5
左缘 = x(l) − 0.5,  右缘 = x(r) + 0.5
```

`l/r` 是 6 bit 轨道号（0…59），`l > r` 由解析层拒绝，故宽度恒为正。

## 布局

横轴 = 轨道（60 格，左→右 = 低轨→高轨），纵轴 = 时间（**向上递增**）。

游戏是下落式的——未来的音符从上方落下。平面视图沿用同一朝向，0 秒在内容底端、总时长在顶端，
读谱方向和游戏里一致。`timeY` 因此以谱面时长 `duration` 为锚。

代价：换轴会把谱面作者用 Hold 画的图形整体上下翻转（爱心、箭头等）。这是该朝向的固有取舍，
同一组航点在游戏视图里也是这个朝向，故与游戏观感一致。

镜像开关即 `x → 左界 + 右界 − x`（等价 `lane → 59 − lane`）。

## 音符几何

单格宽 = 1。音符横跨 `[l, r]`，绘制矩形 `x = l−29.5`，宽 `r−l+1`。

纵向按类型区分（高度单位为秒，随缩放换算为像素）：

| type | 名称 | 高度 | 说明 |
|---|---|---|---|
| 0 | Single | 固定小值 | 瞬时音符，只表达「在什么时刻、什么轨道」 |
| 1 | Hold | 真实时长 `end − time` | 纵向长度即按住时长，这是平面视图最有价值的部分 |
| 2 | Flick | 同 Single | |
| 3 | Trace | 同 Single | |

**不搬 3D 侧的 `worldWidthOf(width) = ((width−6)×0.2+1.15)×0.75`**：那条公式把 60 轨映射到世界宽度 0.15/轨的缩放，是 3D 场景的观感口径，平面视图直接用格宽更忠实。

## Hold 链

一条链由多个节点串成，节点间是**独立的一次位移**，各自可能有 `l2/r2` 与多个 `holds` 航点。

渲染规则：

1. **节点顺序 = 源数组顺序**。同 tick 折返的航点（如谱面用 Hold 画出的图形）靠顺序表达路径，不得按 lane 二次排序。
2. 每个节点内部：从 `(l,r)` 线性插值到 `(l2,r2)`，其 `holds` 给出中间时刻。
3. 链内所有节点的路径连成一条折线，按 `type=1` 的样式绘制。

## 视图参数

| 参数 | 含义 |
|---|---|
| 纵向缩放 | px/s，决定谱面疏密 |
| 轨道宽度 | px/格，60 格总宽 |
| 滚动 | 拖动平移；`Shift + 滚轮` 改纵向缩放、滚轮改轨宽 |
| 镜像 | 左右翻转 |
| 定位 | 把指定时刻滚到视口底边 |
| 分组线 | 按 BPM 段与拍号画小节线（`Bpms` + `Beats`） |

`Beats` 段给出拍号（`Numerator/Denominator`），`Bpms` 给出速度段，二者共同决定小节线位置；`Offset` 为谱面自身偏移，需计入。

| 层 | 内容 |
|---|---|
| 解析 | 四类 Flags、非法值、raw-deflate 解压、16 MiB 上限 |
| 链 | 串链判据（含 float32 容差）、多段链、共享后继 |
| 几何 | `edgeX(0) === padX`、宽度恒正、镜像对合、时间向上、`yTime` 与 `timeY` 互逆、`scrollToBottom` 贴底 |
| 语料 | 对本地 617 张谱面跑解析与几何有限性，记录实际总数 |
| 契约 | 与 `llll-preview-web` 对同一谱面比对音符数、链数、分组数 |
